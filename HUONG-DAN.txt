TỬ VI ĐÔNG A - HƯỚNG DẪN ĐƯA LÊN TÊN MIỀN

Nội dung gói:
  index.html           Trang chính (toàn bộ ứng dụng nằm trong 1 file, không cần cài thêm gì)
  favicon.svg          Biểu tượng tab trình duyệt
  robots.txt           Cho phép công cụ tìm kiếm
  nginx.conf.example   Mẫu cấu hình nếu dùng máy chủ Nginx

Ứng dụng chạy hoàn toàn trên trình duyệt, không cần PHP, database hay máy chủ xử lý.
Chỉ cần đưa các file lên thư mục gốc của tên miền.

CÁCH 1 - Hosting thường (cPanel, DirectAdmin, ...)
  1. Đăng nhập File Manager, mở thư mục public_html (hoặc thư mục gốc của tên miền).
  2. Tải lên các file trong gói (hoặc tải file zip rồi giải nén tại đó).
  3. Mở https://ten-mien-cua-ban.com để kiểm tra.
  Muốn đặt trong thư mục con (ví dụ /tuvi/), tạo thư mục đó rồi tải file vào là được.

CÁCH 2 - VPS dùng Nginx
  1. Chép thư mục này lên /var/www/tu-vi-dong-a
  2. Chép nội dung nginx.conf.example vào /etc/nginx/sites-available/, đổi tên miền, bật site rồi nginx -s reload.
  3. Bật HTTPS: certbot --nginx -d ten-mien-cua-ban.com

CÁCH 3 - Miễn phí (Cloudflare Pages / Netlify / GitHub Pages)
  Kéo thả thư mục này vào trang quản lý, rồi trỏ tên miền về dịch vụ theo hướng dẫn của họ.

CHỈNH SỬA NHANH (mở index.html bằng trình soạn thảo văn bản)
  - Số điện thoại: dùng chức năng Tìm và Thay thế cho cả hai dạng: "079 43 53 630" (số hiển thị, 5 chỗ) và "0794353630" (liên kết bấm gọi, 3 chỗ).
  - Năm xem mặc định: tìm value="2026".
  - Tiêu đề trang và mô tả chia sẻ: nằm ở đầu file, trong thẻ <title> và <meta>.
